# SOTORINO（ソトリノ）再構築キット

家まわり情報メディア「SOTORINO」を、別の環境・別の制作者でも1から作り直せるようにまとめた一式です。
2026年11月3日時点のサイト（コラム150本＋ガイド記事・固定ページ54本、全539ページ）の内容をもとにしています。

## 同梱ファイル（3つのzip）

| zip | 中身 | 使う人 |
|---|---|---|
| `SOTORINO_01_設計書とソース.zip` | 設計書（docs/）、ソースコード（source/）、データ（data/）、画面キャプチャ（screenshots/） | 制作者・ディレクター |
| `SOTORINO_02_画像素材.zip` | 整理済みの画像（images/）と画像台帳 | 制作者・デザイナー |
| `SOTORINO_03_公開用静的サイト.zip` | ビルド済みのHTML一式。そのままサーバーに置ける | 公開担当 |

3つを同じフォルダに展開すると、次の構成になります（ビルドスクリプトはこの配置が前提です）。

```
SOTORINO_rebuild_kit/
├─ README.md            ← このファイル
├─ docs/                ← 詳細設計書（下の「読む順番」参照）
├─ screenshots/         ← 全テンプレートのPC・スマホ画面キャプチャ
├─ data/                ← 記事・サイト構成・デザイントークンのデータ（JSON）
├─ source/              ← ソースコード（npm run build / npm run ssg で再生成）
├─ images/              ← 画像素材（用途別フォルダ＋台帳CSV）
└─ dist/                ← 公開用静的サイト（03のzip）
```

## 最短で動かす

```bash
cd source
node scripts/build.mjs          # src/ と content/ と ../images から public/ を作る
cd public && python3 -m http.server 8080
# → http://localhost:8080/index.html を開く（全ページを確認できるプレビュー版）

cd ..
node scripts/ssg.cjs            # 公開用の静的HTMLを source/dist/ に書き出す（539ページ＋sitemap.xml＋404.html）
node scripts/check.cjs          # 記事データの整合チェック
```

03のzipの `dist/` は、これを実行した結果と同じものです。

必要なのは Node.js 18 以上だけです（追加のnpmパッケージは不要）。サムネイルの生成には Python 3、Pillow、Noto CJK フォントを使います。
