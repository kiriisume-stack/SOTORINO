# 04 画面設計（ページ別レイアウト）

各ページの完成形は `screenshots/` にあります（`_pc` は1280px幅、`_sp` は390px幅）。この章では、上から順にどの部品をどう並べるかを書きます。部品の詳細は 05、データは 07 を見てください。

共通の枠組み：

```
Header（ロゴ／検索／お気に入り／メニュー ＋ グローバルナビ）
Breadcrumb（トップ以外）
<main id="main"> …ページ固有… </main>
Footer（サイト説明／カテゴリ／ガイド／運営情報／PR表記）
```

## スマホ表示の共通ルール

- ヘッダーは60px。グローバルナビは横スクロール、右上のメニューでドロワーが開く。
- 本文15px、左右16px。サイドバーの中身は本文の下に回る。
- 表は横スクロール（上に「← 横にスクロールできます →」）。
- 画像の比率は保つ。カードの多くは2列か1列に変わる。
- タップできる部品は高さ44px以上。

### 広告枠

| 枠ID | 場所 |
|---|---|
| home-infeed | 新着記事の7本目の位置（一覧の横幅いっぱい） |
| home-side | 人気記事ランキングの下（スマホはランキングの後） |
| home-bottom | 読者の質問箱の下（横長・最大970px） |

- 広告コードは `content/ads.json` に `{ "枠ID": "広告コード" }` で書くと、`npm run ssg` で各枠に入ります（見本：`content/ads.sample.json`）。
- コードの無い枠は、本番では何も表示しません。`AD_SLOTS=1 npm run ssg` とすると、点線の「広告枠」の目印を表示して位置を確認できます（プレビューでは常に表示）。
- 枠は `S.AdSlot('枠ID', 'wide|infeed|side')` で、どのページにも追加できます。

### 補足（2026年11月5日）ホームの新着記事は編集部が選んだ12本
- ホームの「新着記事」は、新しい順の自動表示をやめ、`bundle.more.js` の `S.data.homeLatest`（12本のパス）で並べています。人工芝の記事を先頭にして、費用・住宅設備・ウッドデッキ・不動産・補助金・トラブル・リフォーム・くらし・商品・外構・DIYと、カテゴリが偏らないように選びました。
- 入れ替えるときは、このリストのパスを書き換えます。存在しないパスは飛ばし、足りない分は新しい順の記事で補います。
- 「新着記事をもっと見る」（/new/）は、これまでどおり全記事を新しい順に表示します。
