## C. 機能の改善

| No | 項目 | 内容 |
|---|---|---|
| C1 | サイト内検索がコラムを探さない | `S.searchArticles` は `S.data.articles`（30本）だけが対象。コラム150本を対象にするには、静的ページでも検索用の軽い索引（タイトル・抜粋・タグ・URL）を読み込むようにする |
| C2 | 本文の画像 | 対応済み。`images/08_body/` に置けばビルド時に自動で枠へ入る（08 の5章） |
| C3 | 更新日 | 構造化データの `dateModified` が公開日と同じ。記事データに `updated` を持たせて使う |
| C4 | 監修者 | 記事ごとに監修者を表示できる枠（AuthorBox）はあるがデータがない。お金・不動産・住宅設備の記事は監修者がいると信頼性が上がる |
| C5 | トップ以外のOGP画像 | 記事以外のページに `og:image` がない。共通のOGP画像（1200×630）を1枚作って全ページに付ける |
| C6 | 重要記事のサムネイル | 今は全記事がカテゴリ共通背景の自動生成。集客の柱になる記事（No.101, 111, 114, 124, 131, 141 など）はオリジナル写真で作る |
| C7 | コラム本文の画像 | 図解・手順・比較・ビフォーアフターはイラスト213枚で対応済み。残りは写真でしか伝わらない79枚（必須11・推奨6・任意62）。`images/06_needed/SOTORINO_写真の準備リスト.xlsx` |
| C8 | 人工芝以外の特集型カテゴリ | フェンスを2本目の柱にする予定（`S.data.fenceSeries` に章立てのみある） |

## D. 法令・表記の確認

- アフィリエイト・PR：ステルスマーケティング規制（景品表示法、2023年10月施行）に従い、広告を含む枠には「PR」「広告」を表示済み。記事単位でも、アフィリエイトリンクを含む記事は冒頭に表記すること。
- 物販を自社で行う場合は特定商取引法に基づく表記が必要（紹介のみなら不要）。
- キャンペーンを実施する場合は景品表示法の景品規制（懸賞の上限額）と応募規約を確認。
- 施工例・お客様の声を載せる場合は、掲載許可と、実在の事例であることを確認できる状態にしておく。
