# 08 画像仕様と素材管理

## 1. フォルダ構成（images/）

```
images/
├─ image-catalog.csv            ← 全画像の台帳（ファイル・サイズ・比率・状態・画像キー・使用箇所）
├─ 01_photos/                   ← 本番写真（ご提供写真）52枚
│   ├─ scenes/            17枚  外観・庭・外構・室内のシーン写真
│   ├─ products/          11枚  ピックアップ商品・設備の写真
│   ├─ campaign-season/    3枚  季節バナー・キャンペーン
│   └─ video-thumbs/       3枚  動画カードのサムネイル
├─ 02_tentative-in-use/         ← 仮画像（参考デザインの切り出し）。表示中だが差し替え必須 5枚
├─ 03_logo/                     ← ロゴ（logo.png 584×96）
├─ 04_column-thumbnails/        ← コラムのサムネイル150枚（自動生成、960×540）
├─ 05_illustrations/            ← イラスト・背景模様のSVG（コード内に埋め込み済みのものを書き出し）
├─ 06_needed/                   ← これから用意する写真のリスト
│   └─ SOTORINO_写真の準備リスト.xlsx  写真でしか用意できない分だけ（撮り方・ファイル名つき）
├─ 07_pages/                    ← ガイド記事のアイキャッチ {key}.jpg（任意）
└─ 08_body/                     ← 本文の画像枠に入る画像 {スラッグ or key}-{連番2桁}.png/.jpg
    └─ alt.json                 各画像の代替テキスト（ファイル名 → alt）
```

本文の画像は、図解・手順・種類比較・ビフォーアフターを**イラスト（PNG）で作成済み**です（213枚＋既存写真の流用21枚）。イラストの原本は `source/illustrations/`（9章）。

ビルド時（`npm run build`）に 01〜03 は `public/img/` にフラットに、04 は `public/img/col/` にコピーされます。フォルダ分けは管理用で、ファイル名はすべて重複しないようにしています。

## 2. 画像キーの仕組み

部品はファイル名を知らず、**キー**だけを持っています。

```
部品・データ          キー               ファイル
HeroSlider 1枚目  →  hero-01      →  img/photo-garden-dusk.jpg
カテゴリ「庭づくり」 →  cat-garden   →  img/photo-garden-dusk.jpg
商品「ガーデンベンチ」→  prod-bench   →  img/photo-prod-bench.jpg
コラム記事         →  col-{slug}   →  img/col/{slug}.jpg（colRegisterが自動登録）
```

- 対応表は `public/index.html` の `S.setImages({...})` の1か所だけ。1枚の写真を複数のキーで使い回せます。
- 写真を差し替えるときは、同じファイル名で上書きするか、対応表の右側を書き換えます。部品のコードは触りません。
- 未登録のキーは「画像: キー名」と書かれた代替枠になり、レイアウトは崩れません。

### キーの命名

| 接頭語 | 使う場所 | 推奨比率 |
|---|---|---|
| hero-01〜04 | トップのヒーロー | ワイド（2400×1000px以上を推奨） |
| cat-{id} | カテゴリタイル・カテゴリページ | 4:3 |
| feat-{name} | トップの特集記事 | 3:2（大きいカードは写真上に文字） |
| thumb-{name} | 記事カードのサムネイル | 3:2 |
| prod-{name} | ピックアップ商品 | 1:1 に近い（900×822） |
| video-{name} | 動画カード | 16:9 |
| season-{name} | 季節バナー | 16:9 |
| case-{name} | 施工例 | 4:3 |
| fence-{name} | フェンス記事の目的別・施工例 | 3:2 |
| fencetype-{name} | フェンス記事の種類一覧 | 5:2 |
| promo-bg / purpose-bg | 落とし穴カード・目的別ナビの背景 | 自由（暗幕を重ねる） |
| col-{slug} | コラムのサムネイル | 16:9（960×540） |

## 3. 写真の基準

- 自然光の、実在する住宅・庭・外構の写真。記事の内容と一致させる。
- トーンはやや明るめ。緑と木の色が自然に見えるもの。
- 文字は焼き込まない（コラムのサムネイルを除く）。
- 書き出し：JPEG、長辺1400〜1600px（ヒーローは2400px）、品質80前後、プログレッシブ。1枚300KB以内が目安。
- alt は内容を説明する文。隣にタイトルがあるカードのサムネイルは空の alt。
- 人物の顔・表札・車のナンバーが写っていないこと。施工例は施工会社の掲載許可を取る。

## 4. コラムのサムネイル（自動生成）

重要な記事以外は、カテゴリごとの共通写真にタイトル文字を載せたサムネイルを自動で作っています。

| 項目 | 仕様 |
|---|---|
| サイズ | 1200×675で描画 → 960×540で保存（JPEG 品質80） |
| 背景 | カテゴリごとの写真（下表）を少しぼかし、左から右へ暗くなる緑がかったグラデーション |
| 左上 | カテゴリ名のピル（緑） |
| 中央左 | 記事タイトル（Noto Sans CJK Bold、68→62→56→50pxで収まるまで縮小、3行に収まる最大サイズを選ぶ。幅800px、文節で改行） |
| タイトル下 | ゴールドの短い線 |
| 下端 | 左に「SOTORINO COLUMN」（明朝）、右に「No.101」 |

| コラムカテゴリ | 背景の写真 |
|---|---|
| basics | photo-stone-dusk |
| garden | photo-lawn-deck |
| diy | photo-prod-stepstone |
| products | photo-light |
| cost | photo-house-day |
| trouble | photo-white-deck |
| equipment | photo-interior-city |
| reform | photo-reform-living |
| realestate | photo-hiraya-dusk |
| money | photo-wood-balcony |
| lifestyle | photo-front-green |

生成：`python3 scripts/thumbs.py`（全記事）／`python3 scripts/thumbs.py ecocute-jumyou`（指定記事のみ）。Pillow と Noto CJK フォント（`FONT_DIR` で場所を指定）が必要です。

**改行のルール**（`tokens()`）：句読点・「？」「！」の後、ひらがな→漢字／カタカナ／英数字の変わり目、英数字とカタカナの境目で区切れる単位を作り、1行に入るだけ詰めます。それでも入らない長い語は、助詞（は・が・を・に・で・と・の・も）の後ろで折り、行頭に「、。？」などが来ないようにしています。

重要な記事は、オリジナルの写真で個別にサムネイルを作り、`04_column-thumbnails/{slug}.jpg` を上書きしてください（再生成すると上書きされるので、その記事は thumbs.py の対象から外す）。

## 5. 本文の画像枠

コラム本文には、画像が必要な場所に**点線の準備枠**を入れています。写真が届いたら枠を本物の画像に差し替えます。

```html
<figure class="st-slot" data-kind="gallery" data-n="3" data-ratio="4:3">
  <figcaption>症状の写真（エラー表示・水漏れ箇所など）</figcaption>
</figure>
```

| data-kind | 表示 | 枠の数 |
|---|---|---|
| photo | 写真1枚 | 1 |
| gallery | 写真を並べる（2枚は2列、3・5・6枚は3列、4枚は4列） | n（最大6） |
| steps | 工程写真（「工程 1」…） | n（最大6） |
| beforeafter | BEFORE／AFTER の2枚 | 2 |
| diagram | 図解（方眼の枠に「図解を準備中」） | 1 |

### 画像が届いたときの入れ方（本文は書き換えない）

1. `images/08_body/{スラッグ}-{連番2桁}.jpg` の名前で置く（連番は記事の上から数えた画像の順番。ギャラリー・工程は枚数分進む）
2. 代替テキストを `images/08_body/alt.json` に `"ファイル名": "説明"` で追加（無ければ枠の説明文が使われる）
3. `npm run ssg`。ビルド時に `build.mjs` の `injectBody()` が枠に `data-imgs` / `data-alts` を付け、表示時に画像になります

- 画像が1枚も無い枠は**表示されません**（`S.config.showSlots = true` にすると点線の準備枠が見えます。制作中の確認用）
- `.png` / `.svg` はイラスト扱い：白背景・1列で大きく表示し、タップで原寸を開けます。BEFORE/AFTER などのタグは画像側に描いてあるので重ねません
- `.jpg` / `.webp` は写真扱い：枠いっぱいに切り抜き、BEFORE/AFTER のタグを重ねます
- 何を用意すればよいかは `06_needed/SOTORINO_写真の準備リスト.xlsx`

## 9. 本文イラストの原本（source/illustrations/）

本文のイラストはすべて Python で SVG を組み立て、PNG に書き出しています。手で描いたものではないので、文言や数値の修正はコードを直して再出力します。

| ファイル | 内容 |
|---|---|
| lib.py | 共通部品（色・文字幅・寸法線・引き出し線・土・砂利・防草シート・人工芝・道具など） |
| scene.py | 情景部品（家・人・視線・樹木・生垣・フェンス・ブロック塀・車・箇条書き枠） |
| steps_ground.py / steps_more.py | DIY手順（防草シート・人工芝・砂利・花壇・デッキ・フェンスなど 83枚） |
| diagrams.py | 図解 16:9（建ぺい率・セットバック・補助金早見表など 13枚） |
| types_a.py | 種類比較（カーポート・門扉・ブロック・舗装材・目隠しなど 31枚） |
| trouble.py | 庭のトラブルの原因図解とビフォーアフター（27枚） |
| devices.py / misc.py | 住宅設備・リフォーム・土地・防災（59枚） |
| render.cjs | SVG → PNG（Playwright／Noto Sans CJK、1.25倍） |
| install.py | PNG と流用写真を `images/08_body/` に配置し `alt.json` を作る |

再出力の手順：

```bash
cd source/illustrations
OUT=/tmp/ill
for m in steps_ground steps_more diagrams types_a trouble devices misc; do
  python3 $m.py $OUT/$m/svg && node render.cjs $OUT/$m/svg $OUT/$m/png
done
python3 install.py $OUT      # images/08_body/ を作り直す（README.txt 以外は消える）
cd .. && npm run ssg
```

作図のルール：記事本文に書いてある内容だけを描く／数値は本文の数値だけ／「断面イメージ」「上から見たイメージ」など視点を必ず明記／ファイル名は記事の画像枠の連番と一致させる。

## 7. 使っていない画像について

最初の参考デザインから切り出した仮画像（cat-*.jpg、hero-*.jpg、thumb-*.jpg など28枚）は、ご提供写真に置き換え済みなので、このキットには含めていません。仮画像のうち、フェンスの種類一覧の5枚（`02_tentative-in-use/fencetype-*.jpg`）だけはまだ表示に使っています。公開前に差し替えてください。

### 補足（2026年11月4日）
- `install.py` はイラスト（.png）だけを作り直し、届いた写真（.jpg）と代替テキストはそのまま残します。
- `images/03_logo/ogp-default.jpg`（1200×630）と `favicon.png`（512×512）をロゴから作成済み。差し替えるときは同じ名前で上書きします。
- 無料素材サイトの候補リンクは `06_needed/SOTORINO_写真の準備リスト.xlsx` の「無料素材の候補リンク」シート。

### 補足（2026年11月5日）写真の重複を減らした
- ご提供写真を18枚追加しました（`01_photos/scenes/` の photo-turf-dog、photo-turf-family、photo-carport-white、photo-wamodern-sea など。一覧は image-catalog.csv の「11/5追加」）。
- 同じ写真が並ばないように、次の割り当てを変えました。
  - カテゴリパネル（cat-*）：9カテゴリすべて別の写真
  - 基礎知識12枚：外構工事・人工芝・補助金を新しい写真に
  - サムネイルの別名：thumb-turf、thumb-carport、thumb-fence、thumb-subsidy、fence-design など
  - 「理想の外構をプロとつくる」バナー：photo-black-house-light
  - コラムカテゴリ画像：庭・住宅設備・リフォーム
- 専用画像のないガイドページは、カテゴリごとの写真の候補（`bundle.pages.js` の POOL）から、ページ順に1枚ずつずらして割り当てます。以前は名前から計算していたため、隣どうしが同じ写真になることがありました。人工芝の候補は7枚、外構は9枚あります。
- ホームで使う写真の種類は、約23枚から37枚になりました。それでもホームで2回以上出る写真は、同じ記事が「特集」「新着」「ランキング」など複数の欄に出ている場合です（記事ごとのサムネイルは同じにしています）。
