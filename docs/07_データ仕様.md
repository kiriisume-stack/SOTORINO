# 07 データ仕様

| ファイル（data/） | 中身 | 編集する場所（source/） |
|---|---|---|
| `columns.json` | コラム記事150本（正本） | `content/columns.json` |
| `pages.json` | ガイド記事・まとめ・運営情報・フォーム・用語集の54ページ（正本。形式は12章） | `content/pages.json` |
| `column-categories.json` | コラムカテゴリ11件の定義 | `src/bundle.column.js` の `S.colCats` |
| `site-category-rules.json` | サイトカテゴリとコラムの対応ルール | `src/bundle.column.js` の `S.siteCatRules` |
| `site-data.json` | トップ・ナビ・ランキング・商品・質問箱などのサイト構成データ | `src/bundle.src.js`／`bundle.more.js` の `S.data` |
| `image-keys.json` | 画像キー → ファイルの対応（90件） | `public/index.html` の `S.setImages({...})` |
| `tokens.json` | 色・文字・余白・角丸・影・サイズ | `src/tokens.json` |
| `design-system.json` | パターン帳の目次 | （参照用） |

`data/` は書き出した控えです。作業は `source/` 側で行い、必要に応じて控えを更新してください。

## 1. コラム記事（columns.json）

配列で、1要素が1記事です。

| 項目 | 型 | 必須 | 説明 | 例 |
|---|---|---|---|---|
| id | 数値 | ○ | 記事番号（1〜）。並び順と、見出しラベルの切り替えに使う | 101 |
| slug | 文字列 | ○ | URLの末尾。変更禁止 | `ecocute-jumyou` |
| title | 文字列 | ○ | 記事タイトル＝H1＝titleタグ（`｜SOTORINO` は自動付与） | エコキュートの寿命は何年？… |
| metaDescription | 文字列 | ○ | meta description（120字前後） | |
| excerpt | 文字列 | ○ | リード文・カードの説明 | |
| body | HTML文字列 | ○ | 本文（下の「本文の書き方」） | |
| cat | 文字列 | ○ | コラムカテゴリのキー | `equipment` |
| catName | 文字列 | ○ | カテゴリ表示名 | 住宅設備 |
| date | 文字列 | ○ | 公開日 `YYYY.MM.DD` | 2026.10.31 |
| featured | 真偽 | ○ | おすすめ記事（一覧の上部・サイドバー・サイトマップ0.9） | true |
| tags | 文字列配列 | | タグ。関連記事の判定にも使う | ["エコキュート 寿命", …] |
| links | 文字列配列 | | 関連記事として優先表示するスラッグ | ["ecocute-gas-hikaku", …] |
| faq | 配列 | | `[{question, answer}]`。FAQPage構造化データに使う | |
| sources | 文字列配列 | | 記事末の「参考情報・確認事項」 | |
| slots | 文字列配列 | | 本文に入れた画像枠の説明（管理用） | ["図解：…×1"] |
| category | 文字列 | | 入稿時のカテゴリ名（控え） | |
| mainKeyword / relatedKeywords | 文字列／配列 | | 入稿時の狙いキーワード（101〜150） | |
| searchIntent / targetReader | 文字列 | | 検索意図・想定読者（101〜150） | |
| internalLinkCandidates | 配列 | | 入稿時の内部リンク候補（links の元） | |
| status | 文字列 | | 入稿時の状態 | 完成 |

画面と静的書き出しで使うのは、id〜slots の15項目です（`build.mjs` の `keep`）。それ以外は管理用として正本に残しています。

### 現在の統計
- 150本。featured 18本、links あり 48本、faq あり 50本（101〜150）
- 公開日：1〜100は 2026.09.11〜10.30、101〜150は 2026.10.07〜10.31（どちらも入稿順に割り振った仮の日付。公開時に実際の日付へ直す）

## 2. 本文の書き方（body）

使えるタグは `h2` `h3` `p` `ul` `ol` `li` `table` `thead` `tbody` `tr` `th` `td` `strong` `a` `br` のみ。classやstyleは書きません（見た目は表示側で付けます）。

### 推奨の見出し構成（101〜150で採用）

```html
<h2>（読者の悩みを言い当てる問いかけ）</h2>          ← 1つ目のH2は「問いかけ枠」になる
<p>…</p>
<h2>結論：（先に答え）</h2>                           ← 答えボックス
<p>…</p>
<h2>基礎知識：（前提の説明）</h2>
<h2>詳細解説：（本題）</h2>
<h2>比較・判断基準：（選び方）</h2>  または <h2>比較・判断基準</h2>
<h2>注意点</h2>                                       ← 注意の装飾＋あわせて読みたい
<h2>よくある質問</h2>
<p><strong>Q. 質問</strong><br>A. 答え</p>（繰り返し）  ← 取り込み時に開閉式FAQへ変換
<h2>まとめ</h2>                                       ← まとめ枠
<p>…</p>
```

1〜100の記事は接頭語なしの自由な見出しで書かれており、「比較」「違い」「注意」「失敗」などの語や、直後の表から装飾が決まります（05 の4章）。

### 特別な書き方

| 書き方 | 意味 |
|---|---|
| `関連記事「タイトルの一部」` ／ `別記事「…」` | 取り込み時に、タイトルが一致する記事へのリンク `<a href="{{col:slug}}">` に変換 |
| `<a href="{{col:スラッグ}}">` | 表示時にその記事のURLへ置換（スラッグが変わっても壊れない） |
| `<figure class="st-slot" data-kind="gallery" data-n="3" data-ratio="4:3"><figcaption>説明</figcaption></figure>` | 画像の準備枠（08 参照） |
| `<div class="st-faq">…</div><!--/faq-->` | 開閉式FAQ（取り込みスクリプトが生成。手で書かない） |

## 3. コラムカテゴリ（S.colCats）

```js
{ key: 'equipment',                        // URLとデータで使うキー
  name: '住宅設備',                         // ラベル・ナビの表示名
  full: '住宅設備（給湯・水まわり・省エネ）', // カテゴリページの見出し・title
  icon: 'drop',                             // S.icon の名前
  img: 'photo-interior-city',               // カテゴリカードの写真キー（＝サムネ背景）
  desc: '…' }                               // カテゴリページの説明・description
```

あわせて次の3か所も揃えます。

1. `src/bundle.src.js` の `TONE` に `'col-{key}': 'outdoor'|'home'|'property'|'life'`（ラベル色）
2. `scripts/thumbs.py` の `BG` に `{key}: '写真キー'`（サムネの背景）
3. `scripts/import-articles.py` の `CAT` に `'入稿時のカテゴリ名': '{key}'`
4. 必要なら `S.siteCatRules` の `cats` に追加（サイトカテゴリに載せる）

## 4. サイトカテゴリのルール（S.siteCatRules）

```js
equipment: {
  kw: /宅配ボックス|立水栓|…|給湯|エコキュート|…/,  // タイトルにこの語があれば載せる
  cats: ['equipment'],                                // このコラムカテゴリの記事は全部載せる
  intro: 'エコキュート・給湯器・…'                    // ハブページの紹介文・description
}
```

キーの id は `S.data.nav` / `S.data.categories` の id と一致させます（garden, exterior, carport, deck, equipment, reform, realestate, money, life）。

注意：庭づくり（garden）の `kw` の「土」は `土(?!地)` にして「土地」に反応しないようにしています。同じような誤検知に気を付けてください。
