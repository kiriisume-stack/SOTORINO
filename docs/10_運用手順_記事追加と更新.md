# 10 運用手順（記事の追加と更新）

作業はすべて `source/` で行います。最後に必ず `npm run check` → `npm run ssg` を実行して、`dist/` を公開し直してください。

## 1. 記事を追加する（入稿JSONから）

これまでの入稿ファイル（`category*.json`）と同じ形式なら、スクリプトで取り込めます。

```bash
cd source
python3 scripts/import-articles.py ~/入稿/category12-xxxx.json
npm run thumbs        # 新しい記事のサムネイルを作る（全件作り直す。指定するなら slug を並べる）
npm run check         # 整合チェック
npm run ssg           # 公開用HTMLを作る
```

取り込みスクリプトがやること：

1. `seoTitle` を `title` に、カテゴリ名をキーに変換（`CAT` 表）
2. 公開日（既存記事は元の日付を維持、新規は実行日）、`featured`、`tags`（mainKeyword＋関連キーワード3つ）を設定
3. `internalLinkCandidates` のうち実在するスラッグを `links` に
4. 「よくある質問」の Q./A. 段落を開閉式FAQに変換
5. 本文の「関連記事『〇〇』」をリンクに変換
6. `imageSlots` があれば、指定の見出しの後に画像枠を入れる
7. 同じ id があれば上書き、なければ追加

`imageSlots` の書き方（入稿JSONの各記事に追加）：

```json
"imageSlots": [
  {"after": "基礎知識", "label": "図解：ヒートポンプの仕組み", "n": 1, "kind": "diagram", "ratio": "16:9"},
  {"after": "詳細解説", "label": "症状の写真", "n": 3, "kind": "gallery", "ratio": "4:3"}
]
```

`after` は見出しの書き出し部分（例：「基礎知識」は「基礎知識：〜」のH2に一致）。

おすすめ記事にしたいときは、スクリプト冒頭の `FEATURED = {101, 131}` のように id を入れるか、取り込み後に `content/columns.json` の `featured` を `true` にします。

## 2. 記事を手で直す

`content/columns.json` を直接編集します（UTF-8、JSONとして正しいこと）。

- タイトル・説明・本文はそのまま書き換えてOK。
- **slug は変えない。** どうしても変えるときは、旧URLから新URLへの301リダイレクトをサーバー側に設定する。
- 内容を見直したら `date` はそのまま、更新日を持たせたい場合は項目 `updated` を追加し、`colSeo` の `dateModified` に使うよう1行直す（現在は公開日と同じ値を出力）。
- 本文中で他の記事にリンクするときは `<a href="{{col:スラッグ}}">` と書く。

## 3. 本文の画像枠を本物の画像にする

1. 画像を `images/` 配下（例：`images/07_column-body/`）に置く。`build.mjs` のコピー対象に追加する
2. `content/columns.json` の該当記事の本文で、`<figure class="st-slot" …>…</figure>` を `<figure class="st-figure"><img …><figcaption>…</figcaption></figure>` に置き換える
3. `colBody` の正規表現に通常の figure を追加（08 の5章、11 参照）
4. （本文は書き換え不要）`images/08_body/{スラッグ}-{連番}.jpg` を置いて `npm run ssg` するだけで入ります。詳しくは 08 の5章

## 4. トップ・サイト構成を変える

`src/bundle.src.js` の `S.data`（一部は `bundle.more.js`）を直します。

| 変えたいもの | 場所 |
|---|---|
| 上部メニュー | `S.data.nav` |
| カテゴリタイル | `S.data.categories` |
| 特集・新着・ランキング・おすすめ | `features` `latest` `ranking` `editorsPick`（記事IDの配列） |
| ヒーロー写真 | `heroSlides` と画像キー `hero-01〜04` |
| キャンペーン・季節バナー | `campaigns` `campaignNews` |
| 商品 | `pickupProducts`（価格は取得日を確認して更新） |
| 質問箱 | `qaCats` |
| フッター | `footer` |

トップの特集・ランキングに**コラム記事**を出したいときは、`S.data.articles` にそのコラムの情報（id, cat, title, desc, img, date, path=`/column/{slug}/`）を1件足して、そのIDを `features` などに入れます。

## 5. 写真を差し替える

- 同じ見た目のまま写真だけ替える：`images/01_photos/…/` の同名ファイルを上書き → `npm run ssg`
- 別のファイルを使う：`public/index.html` の `S.setImages({...})` で、キーの右側のファイル名を変更
- 新しいキーを足す：データ（例：`pickupProducts` の `img`）に新しいキー名を書き、`setImages` に対応を追加
- `images/image-catalog.csv` も更新しておく

## 6. コラムカテゴリを追加する

07 の3章のとおり、次の4〜5か所を揃えます。

1. `src/bundle.column.js` の `S.colCats` に1件追加（key, name, full, icon, img, desc）
2. `src/bundle.src.js` の `TONE` に `'col-{key}'` の色系統
3. `scripts/thumbs.py` の `BG` にサムネ背景の写真
4. `scripts/import-articles.py` の `CAT` に入稿時のカテゴリ名
5. 必要なら `S.siteCatRules` の `cats` に追加

URL `/column/category/{key}/` とサイトマップは自動でできます。

## 7. サイトカテゴリ（上部メニュー）に載る記事を調整する

`S.siteCatRules` の `kw`（タイトルのキーワード）と `cats`（コラムカテゴリ）を調整します。調整後は `npm run check` で「どのサイトカテゴリにも載らない記事」が出ないことを確認します。

## 8. 整合チェック（npm run check）

`scripts/check.cjs` が次を確認します。

| 種類 | 内容 |
|---|---|
| エラー | id／slug／title の重複、slug の文字種、未定義のカテゴリ、metaDescription なし、日付の形式、links や本文リンク先のスラッグが存在しない、表示に未変換の文字（`__CHEV__` など）が残っている |
| 注意 | どのサイトカテゴリにも載らない記事、サムネイル画像がない |
