## 2. データ：content/pages.json

```json
{
  "kind": "article",                 // article | hub | info | form | glossary
  "key": "turf-basics",              // 画像ファイル名などに使う識別子
  "path": "/garden/turf/basics/",    // URL（末尾スラッシュ）
  "title": "人工芝の基礎知識｜…",      // H1 と title（｜SOTORINO は自動付与）
  "description": "…",                // meta description
  "excerpt": "…",                    // リード文・カードの説明
  "date": "2026.11.03",
  "cat": "turf",                     // ラベル色・ナビ（サイトカテゴリID）
  "colCat": "garden",                // 本文中「あわせて読みたい」を探すコラムカテゴリ
  "crumbs": [["庭づくり","/garden/"],["人工芝ガイド","/garden/turf/"]],
  "series": "turf",                  // サイドバーのシリーズ一覧：turf | trap | shiba | fence | beginner
  "tags": ["人工芝", "人工芝 種類"],
  "links": ["jinkoshiba-shurui-erabikata", "/garden/turf/quality/"],  // 関連記事（コラムのスラッグ or ページのパス）
  "body": "<h2>…</h2><p>…</p>…",     // コラムと同じ書き方。{{col:スラッグ}} と {{p:/パス/}} でリンク
  "faq": [{"q": "…", "a": "…"}],     // FAQPage 構造化データにも使う
  "sources": ["…"],
  "imgFallback": "photo-lawn-deck",  // 専用画像がないときに使う写真
  "video": "https://www.youtube.com/watch?v=…"  // 動画ページ：入れると点線枠が埋め込み動画になる
}
```

- hub は `sections`（`title` / `items` / `auto:{cats:[…]}` / `component:'CaseGallery'` など / `style:'list'`）で一覧を組みます。
- form は `form: {name, submit, fields:[{name,label,type,required,options,hint}]}` で入力項目を定義します。type は text / email / tel / url / select / textarea / checks。
- glossary は `terms: [{id, t, yomi, d, link}]`。yomi（ひらがな）で五十音に自動で振り分けます。
- 本文の見出し装飾（問いかけ枠・結論ボックス・基礎知識タグなど）はコラムと同じルールで自動で付きます（05 の4章）。

## 3. 画像を入れるだけで完成する仕組み

| 置く場所 | ファイル名 | 入る場所 |
|---|---|---|
| `images/07_pages/` | `{key}.jpg`（例：turf-basics.jpg） | ガイド記事のアイキャッチ・カード・OGP。置くまではカテゴリの共通写真を表示 |
| `images/08_body/` | `{スラッグ or key}-{連番2桁}.jpg`（イラストは .png）（例：ecocute-jumyou-01.png） | 本文の画像枠。連番は記事の上から数えた画像の順番。画像の無い枠は表示されない |
| `images/03_logo/` | `ogp-default.jpg`（1200×630）、`favicon.png` | 全ページのSNS共有画像・タブのアイコン |
| `content/pages.json` の `video` | YouTubeのURL | 動画ページの点線枠が埋め込み動画になる |

置いたら `npm run ssg` を実行するだけです。まだ用意が必要な写真は `images/06_needed/SOTORINO_写真の準備リスト.xlsx` に、撮り方とファイル名つきで書いてあります（イラストで対応済みの分も別シートに一覧）。

## 4. フォームの送信先

PHPを使わないため、フォームの受け付けは外部サービスを使います。

| 方法 | 設定 |
|---|---|
| Netlify にデプロイする場合 | 設定不要。フォームは Netlify Forms の形式（`data-netlify="true"`）で出力済み。管理画面で通知先メールを設定 |
| Formspree などのフォームサービス | `FORM_ENDPOINT=https://formspree.io/f/xxxx npm run ssg` で送信先を指定。送信は非同期で行い、完了メッセージを表示 |
| どちらも未設定 | 送信ボタンを押すと「ただいまフォームの受付準備中です」と表示（送信されない） |

迷惑投稿対策として、見えない入力欄（honeypot）を入れています。すべてのフォームにプライバシーポリシーへの同意チェックがあります。

## 5. ルーティングの共通化

ページの判定は `S.route(path)` 1か所にまとめました。プレビュー（`public/index.html`）と静的書き出し（`scripts/ssg.cjs`）が同じ関数を使うので、表示とSEO情報（title・description・構造化データ・noindex・prev/next）が必ず一致します。書き出すURLの一覧は `S.allPaths()` が返します。

## 6. サイト内検索

`npm run build` が `public/search.js`（コラム・ガイド記事・トップ用記事の200件の索引）を作ります。静的ページでもヘッダーの検索候補と `/search/?q=…` の検索結果が全記事を対象に動きます。

## 7. 運営者情報の扱い

運営者名・所在地・代表者・執筆者名・監修者名・制定日などの個人や会社を特定する情報は、現時点ではサイトに**掲載していません**。運営者情報ページは「サイト名・URL・運営（SOTORINO編集部）・お問い合わせ」だけを表示し、監修者一覧は「決まりしだい掲載」としています。掲載する場合は `content/pages.json` の該当ページ（about / editors / supervisors / privacy）に追記してください。本文中に `［要記入：…］` と書くと、黄色の目印つきで表示される仕組みも残してあります。

## 8. アフィリエイト（承認が下りるまで非公開）

アフィリエイトの承認前に商品リンクがクリックされないよう、商品の紹介はすべて**スイッチ1つで非公開**にしています。

| | 非公開（現在） | 公開（承認後） |
|---|---|---|
| トップ「編集部ピックアップ商品」 | ぼかした商品の上に「COMING 2027／2027年に掲載予定です」の案内。商品へのリンクなし | 商品12点を表示。「もっと見る」から商品ページへ |
| 商品ページ `/products/pickup/` | 書き出さない（URLを開いても404）。サイトマップにも載らない | 公開（選定基準・PR表記・商品一覧・選び方の記事） |
| 記事内の商品カード（フェンス特集など） | 「おすすめ商品の紹介は準備中です」の案内に置き換え。販売サイトへのリンクなし | 商品カード（販売サイトへのボタン付き）を表示 |
| 目的別「おすすめ商品を探したい」 | 予告を表示 | 商品一覧を表示 |
| フッターの表記 | 「広告を含むコンテンツには『PR』と表示しています。」 | 先頭に「当サイトはアフィリエイトプログラムを利用しています。」を追加 |

**公開するとき**：`AFFILIATE=1 npm run ssg` で書き出すだけです（プレビュー版は `public/index.html` の `S.config.affiliate = false` を `true` に）。その前に `src/bundle.src.js` の `pickupProducts`（商品名・価格）と、フェンス特集の商品カードの販売先リンクを、承認されたアフィリエイトリンクに差し替えてください。
