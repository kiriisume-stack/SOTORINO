## 3. 必須要件（オーナー指定）

制作時の指示書で決まっている要件です。作り直すときも必ず満たしてください。

| No | 要件 | 現在の実装 |
|---|---|---|
| R1 | 本文がHTMLに入った状態で配信する（SSR または SSG） | `scripts/ssg.cjs` で静的HTMLを生成。JSを切っても本文が読める |
| R2 | 記事ごとに title と meta description を出し分ける | 記事データの `title`・`metaDescription` を使う |
| R3 | 構造化データ Article と BreadcrumbList | 全記事に出力。FAQがある記事は FAQPage も追加 |
| R4 | URLは渡されたスラッグをそのまま `/column/{slug}/` に使う | そのとおり。スラッグは変更しない |
| R5 | 関連記事は同じカテゴリから3〜4本＋カテゴリをまたぐキーワードのリンク | 06 の「関連記事の決め方」参照 |
| R6 | カテゴリごとにピラーページ（まとめページ） | コラムカテゴリ11ページ＋サイトカテゴリ9ページ |
| R7 | ページ送りは本物の `<a href>` リンク | `/column/page/2/` 形式。rel="prev/next" も出力 |
| R8 | XMLサイトマップ | `dist/sitemap.xml`（196URL、lastmod・priority付き） |
| R9 | サムネイルは遅延読み込み。ただし最初の画面に見えるものは除く | `loading="lazy"`。ファーストビューは `fetchpriority="high"` |
| R10 | モバイルファースト | 390px幅で横スクロールなし。各テンプレートのSP画面は screenshots/ 参照 |
| R11 | 見出しのデザインに変化をつけ、テンプレート感を出さない | 見出しの種類ごとにラベル・装飾を変え、記事IDで文言をローテーション（05・07参照） |
| R12 | **PHPは使わない** | HTML/CSS/JSのみ。ビルドは Node.js |
| R13 | SEO と内部リンクを最優先 | 06 にまとめた回遊設計 |

## 4. 技術方針

- **フレームワークなしの素のJavaScript。** すべての部品は「HTML文字列を返す関数」です（`window.Sotorino.XXX()`）。同じ関数をブラウザでもNode.jsでも動かせるので、プレビューと静的書き出しで同じ見た目になります。
- **2つの出力。**
  1. プレビュー版（`public/index.html`）：1枚のHTMLにハッシュルーター（`#/column/...`）を載せた、全ページを確認するための版。
  2. 公開版（`dist/`）：ページごとの静的HTML。本文がHTMLに入っていて、URLは通常のパスです。公開はこちらを使います。
- **データとデザインを分ける。** 記事は `content/columns.json`、サイト構成は `src/bundle.src.js` 内の `S.data`、色や余白は `src/tokens.json`。部品の中に文章を直書きしません。
- **画像はキーで参照。** 部品は「hero-01」のようなキーだけを持ち、実ファイルとの対応は1か所（`index.html` の `S.setImages`）で管理します。
- **サーバー側の処理は不要。** 静的ホスティング（Netlify、Cloudflare Pages、さくらの静的領域、S3など）で動きます。

### 別の技術で作り直す場合

Next.js、Astro、WordPress（PHP不可のためヘッドレス運用）などに移す場合も、次の3つは流用できます。

- `data/columns.json`（記事データ）と `data/site-data.json`（サイト構成データ）
- `source/src/sotorino.css` と `data/tokens.json`（見た目すべて）
- 各部品が出力するHTML構造（05 の仕様と screenshots/ を正とする）

Astroなら、各部品の関数をそのまま `.astro` のテンプレートから呼び出して静的書き出しできます。手を入れる量がいちばん少なく済みます。

## 5. 文章・表現のルール

- 丁寧語（です・ます）。読者を「あなた」と呼ばず、主語を省いて自然に語りかける。専門用語は初出で説明する。
- 煽らない。「絶対」「最強」「今すぐ」は使わない。CTAは内容がわかる動詞で終える（「無料見積もりを依頼する」「カタログをみる」）。
- 数値・耐久年数・費用は、出典と条件を添えられるものだけ断定する。未確認の数値は載せない。デザイン上の仮置きは「◯」。
- DIYと業者依頼は公平に書く。体験していないことを体験談として書かない。
- 絵文字は使わない。英字はセクション見出し横の飾り（FEATURE など）だけ。
- 広告・アフィリエイトを含む枠には必ず「PR」表記を付け、リンクに `rel="sponsored"` を付ける。
