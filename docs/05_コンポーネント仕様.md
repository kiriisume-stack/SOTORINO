# 05 コンポーネント仕様

## 1. 基本の仕組み

- すべての部品は `window.Sotorino` の関数で、**HTML文字列を返す**だけです（副作用なし）。
- 画面に出したあと `Sotorino.mount(要素)` を呼ぶと、動き（スライダー、タブ、検索候補、目次、お気に入り、ドロワー、コピー）が結び付きます。`Sotorino.render(el, html)` は「innerHTML に入れて mount する」の省略形です。
- ルート要素に `class="st"`。部品のクラス名はすべて `st-` で始まる BEM 風（`st-card__title`、`st-btn--accent`）。
- 引数の型定義は `source/src/sotorino.d.ts`。
- ソースの場所：

| ファイル | 中身 |
|---|---|
| `src/bundle.src.js` | 基本部品、サイトデータ `S.data`、アイコン、記事本文ブロック、トップ／特集記事／人工芝カテゴリ、動きの結び付け（mount） |
| `src/bundle.more.js` | トップ拡張（落とし穴・職人コラム・動画・施工例・商品・質問箱・エリア・季節バナー）、連載・質問箱・キャンペーンページ |
| `src/bundle.column.js` | コラムの仕組み一式（カテゴリ、一覧、記事、関連記事、本文変換、SEO）とサイトカテゴリのハブ |

## 2. 共通ユーティリティ

| 関数 | 役割 |
|---|---|
| `S.esc(s)` | HTMLエスケープ |
| `S.href(path)` | `config.base` を付けたリンク先（プレビュー `#/x/`、公開 `/x/`） |
| `S.icon(name, cls)` | 線画アイコンのSVG（`S.iconNames` に一覧。search, heart, menu, close, arrow, chevL/R/D, clock, update, home, check, eye, lock, house, leaf, wind, yen, coins, image, cart, user, doc, alert, info, bulb, link, book, pause, play, pin, shield, tool, tag, calendar, copy, plus, minus, share, chat, sprout, ruler, drop, sun, paw, layers, scale ほか） |
| `S.img(key, alt, opt)` | 画像キーから `<img>`。`opt.eager` で遅延読み込みを外す。未登録キーは「画像: キー名」の代替枠 |
| `S.media(key, alt, ratio)` | 比率固定の枠つき画像 |
| `S.setImages(map)` | 画像キーと実ファイルの対応を登録 |
| `S.config` | `base`（'#' or ''）、`logoSrc`、`favoritesKey`、`autoplayMs`(6500) |

## 4. 本文の見出し変換（colBody）

コラム本文はシンプルなHTML（h2/h3/p/ul/ol/table）で入稿し、表示時に次のように装飾を変えます。どの記事も同じ見た目にならないよう、ラベルの文言は記事IDで順番に切り替えます。

| 入稿時の見出し | 表示 | ラベル候補（記事IDで切り替え） |
|---|---|---|
| 最初のH2 | 問いかけ枠 `.st-qhead` | こんな疑問に／はじめに／よくある悩み／この記事のテーマ |
| `結論：…` | 緑枠の答えボックス `.st-answer`（「結論：」は消す） | 先に結論／この記事の答え／結論から言うと／ひとことで言うと |
| `基礎知識：…` | `.st-h2--basic`（接頭語を消してタグに） | 基礎知識／まず知っておきたい／仕組みを知る／基本をおさえる |
| `詳細解説：…` | `.st-h2--detail` | くわしく解説／詳しく見る／深掘り／ポイント解説 |
| `比較・判断基準：…` | `.st-h2--judge` | 判断の基準／選び方の目安／どう決める？／比べて選ぶ |
| 「注意」「リスク」「失敗」「後悔」を含む | `.st-h2--caution`（ここで「あわせて読みたい」を挿入） | 注意／気をつけたい点／見落としがち／チェック |
| 「比較」「違い」を含む、または直後が表 | `.st-h2--compare` | 比較／一覧で比べる／違いを整理／比べてみる |
| `よくある質問` | `.st-h2--faq`（見出し文は「気になる疑問に答えます」） | よくある質問／Q&A／気になる疑問／みんなの疑問 |
| `まとめ` | まとめ枠 `.st-wrap--col` | まとめ／この記事のおさらい／要点のおさらい／ポイントのふり返り |
| 見出しだけの「注意点」「比較・判断基準」 | 「注意しておきたいこと」等に言い換え | — |

そのほかの変換：

- `<ul>` → `.st-ul`、`<ol>` → 番号の丸つき `.st-olist`、`<table>` → 横スクロール枠
- `<figure class="st-slot" …>` → 画像の準備枠（08 参照）
- `<div class="st-faq">…</div><!--/faq-->` → 開閉式FAQ（`__CHEV__` を矢印アイコンに置換）
- `{{col:スラッグ}}` → その記事のURL（存在しなければ /column/）
- 目次には接頭語を消した見出しを入れる

## 5. 動き（mount が結び付けるもの）

| 属性 | 動き |
|---|---|
| `data-st-slider` | ヒーロースライダー（自動再生・一時停止・前後・ドット、reduced-motion対応） |
| `data-st-tabs` | ランキング等のタブ（矢印キーで移動、`role="tablist"`） |
| `data-st-search` / `data-st-search-toggle` | 検索候補の表示。狭い画面ではヘッダーの虫眼鏡で検索欄を開閉 |
| `data-st-drawer-open` / `-close` | スマホ用メニュー（ドロワー）の開閉。`role="dialog"`、背景タップ・閉じるボタンで閉じる |
| `data-st-check` / `-count` | チェックリストの数を数える |
| `data-st-copy` / `-status` | URLのコピーと「コピーしました」表示 |
| お気に入り | ハートボタン。`localStorage`（キー `sotorino:favorites`）に保存。読み書きは try/catch |
| 目次 | 開閉と、スクロール位置に合わせた現在地表示 |

## 6. デザインシステム（パターン帳）

各部品の見本・使い方は、claude.ai 上のデザインシステム（パターン帳）にまとまっています。`data/design-system.json` はその目次データです。パターン帳はそのまま残してあり、この再構築キットとは別に参照できます。
