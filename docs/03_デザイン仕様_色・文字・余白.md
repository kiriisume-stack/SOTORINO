# 03 デザイン仕様（色・文字・余白）

数値の正本は `data/tokens.json` です。`source/scripts/build.mjs` がこれを CSS カスタムプロパティ（`public/tokens.css`）に変換し、`sotorino.css` は必ず `var(--名前)` で参照します。色や余白を変えるときは tokens.json だけを直してください。

### コラムカテゴリとラベル色の対応

コラムカテゴリのラベルは4系統の色を使い回します（`TONE` 対応表、`src/bundle.src.js`）。

| 系統 | 色 | 対象 |
|---|---|---|
| outdoor | primary | col-basics, col-garden |
| home | wood-text | col-products, col-trouble, col-equipment, col-reform |
| property | cat-property | col-cost, col-realestate, col-money |
| life | cat-life | col-diy, col-lifestyle |

色だけで見分けさせず、必ずカテゴリ名を文字で表示します。

### 使わないもの
原色、強いグラデーション、青紫系、色付きの左ボーダーで囲んだカード（左バーはH2専用）、ポップアップ広告、追従広告。

| トークン | 値 | 用途 |

| radius-sm | 4px | ラベル、小サムネイル |
| radius-md | 8px | カード画像、ボタン、ボックス |

## 5. ブレイクポイント

CSSは「PCの指定 → 狭い幅で上書き」の順で書かれています。

| 幅 | 主な変化 |
|---|---|
| 〜1180px | トップの新着・目的別ナビ・ピックアップ商品・ランキング周りの列数と文字サイズを詰める |
| 〜1080px | 記事ページ・一覧ページのサイドバーを本文の下へ回して1列に。カテゴリタイル、プロモカード（落とし穴・職人コラム）を組み替え |
| 〜900px | トップの特集ブロックと右サイドを縦積みに。ヘッダーの検索欄を虫眼鏡ボタンに。フッター段組み・落とし穴セクション・サイトカテゴリのヒーローを1列に |
| 〜760px | スマホ表示。左右余白16px、本文15px、ヘッダー60px、見出しを縮小、カード1〜2列、表は横スクロール（「← 横にスクロールできます →」を表示） |

確認する幅は390px、768px、1280pxです。どの幅でも横スクロールが出ないこと（`document.documentElement.scrollWidth === innerWidth`）。

## 6. 動き

- ヒーロースライダー：6.5秒ごとに1.2秒のクロスフェード。写真はゆっくり拡大から等倍へ。一時停止ボタン付き。マウスオーバー・フォーカス中は止める。
- ホバー：サムネイルを4%拡大、タイトルに下線、矢印を3px右へ。トランジションは0.2秒。
- 「視差効果を減らす」設定（`prefers-reduced-motion: reduce`）では自動再生とズームを止める。

## 7. 背景の装飾

上品さと安心感を出すため、セクションの背景に薄い帯と植物の線画を敷いています（`.st-band` 系のクラス）。

| クラス | 見た目 |
|---|---|
| `.st-band--soft` | bg-soft の帯＋左下に波線の模様（不透明度10%） |
| `.st-band--green` | 薄い緑の帯 |
| `.st-band--leaf` / `--leaf-l` | 右（左）に葉の線画 |
| `.st-band--sprig` | 小枝の線画 |
| 波の切り替え | 帯の上下に緩やかな波形 |

模様のSVGは `images/05_illustrations/bg-pattern-*.svg` に書き出してあります（CSSにはdata URIで埋め込み済み）。
